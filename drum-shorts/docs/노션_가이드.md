# 드럼 패턴 쇼츠 만들기 가이드

> 미디 파일과 드럼 샘플만 있으면, Claude가 **드럼 패턴 설명 쇼츠(세로 영상, 약 18초)** 를 만들어 줘요.
> 코딩이나 프로그램 설치는 필요 없어요. Claude와 대화만 하면 돼요.

---

## 1. 어떤 영상이 나오나요?

📎 *(여기에 완성 예시 영상 `uk-garage.mp4` 첨부)*

| 순서 | 장면 | 내용 |
|---|---|---|
| 1 | 미리보기 | 완성된 비트를 먼저 들려줌 |
| 2 | 킥 | 킥 위치 설명 |
| 3 | 스네어 | 킥 + 스네어 |
| 4 | 햇 | 킥 + 스네어 + 햇 |
| 5 | 스윙 | 셔플을 켜면 어떻게 바뀌는지 (스윙 없는 장르는 생략) |
| 6 | 전체 | 완성 비트 |
| 7 | 마무리 | "댓글 남기면 미디 DM" 안내 + 페이콜라보 로고 |

- 화면 크기: 720×1280 (유튜브 쇼츠, 인스타 릴스용)
- 소리와 화면은 자동으로 맞춰져요.

## 2. 전체 흐름

```
① 재료 준비  →  ② Claude에게 요청  →  ③ 대본 확인·수정  →  ④ 영상 받기  →  ⑤ 공유 폴더에 저장
```

한 편 만드는 데 **약 10~20분** 걸려요. 대부분 대본을 확인하는 시간이에요.

## 4. 재료 준비 체크리스트

압축 파일(zip) **하나**로 묶어 주세요.

| 재료 | 필수 | 설명 |
|---|---|---|
| 미디 파일 | ✅ | 악기별로 따로 있어도 되고, 한 파일에 다 있어도 돼요 |
| 원샷 샘플 (wav) | ✅ | 킥, 스네어, 햇 등 악기마다 1개 |
| 마스터 wav | 선택 | 있으면 악기별 볼륨을 이것과 똑같이 맞춰줘요 |

그리고 아래 정보를 미리 정해 두세요.

| 정보 | 예시 |
|---|---|
| 장르 이름 (영문) | UK Garage |
| BPM | 130 |
| 스윙 | 33ms / 없음 |
| 킷 이름 (한글 가능) | 페이콜라보 개러지 킷 |
| 에피소드 번호 | 2 (오른쪽 위 "DRUM PATTERN 002") |

💡 악기는 **최대 4개**까지 넣을 수 있어요. 미디 파일 이름이 실제 악기와 달라도 괜찮아요. Claude가 내용을 보고 판단해서 확인을 받아요.

## 5. Claude에게 요청하기

새 작업을 열고, 아래 문구를 **복사해서 붙여넣은 뒤** 빈칸을 채우고 zip 파일을 첨부하세요.

```
드럼 패턴 쇼츠를 새 장르로 만들고 싶어요.
CLAUDE.md에 있는 '드럼 패턴 쇼츠' 작업 순서대로 진행해 주세요.

- 장르 이름: 
- BPM: 
- 스윙: 
- 킷 이름: 
- 에피소드 번호: 

재료 zip 첨부합니다.
```

그러면 Claude가:
1. 재료를 확인하고, 악기가 맞는지 물어봐요 → 맞으면 "네"라고 답하면 돼요.
2. **대본 파일(`장르_대본.txt`)** 을 보내줘요.

## 6. 대본 확인하기 (가장 중요!)

대본 파일은 이렇게 생겼어요.

```
[2] 킥  1.8~5.5초
킥은 1박 첫 칸과 3박 세 번째 칸에!
3박 정박을 비워두는 게 핵심이에요.
```

### 고치고 싶을 때
장면 번호와 함께 말해 주세요.
- "2번 자막을 ○○○로 바꿔줘"
- "4번에서 '뒤쪽 두 칸'을 주황색으로 강조해줘"
- "4번 장면이 너무 빨라. 2마디로 늘려줘"

### 대본 쓰는 요령
- 박자는 **"N박 M번째 칸"** 으로 써요. 화면의 칸과 그대로 맞아서 초보자도 쉽게 따라와요.
  - ⭕ "3박 세 번째 칸"  ❌ "3박의 앤"
- 1마디 장면(약 1.8초)은 **두 줄 이내, 짧게** 써요.
- 가운뎃점(·) 같은 특수문자는 피해요. 영상에서 글자가 깨질 수 있어요.
- 걱정하지 마세요. Claude가 **자동 검사**로 글자 넘침, 미디와 다른 내용, 너무 긴 자막을 알려줘요.

### 다 됐으면
**"대본 확정, 영상 만들어줘"** 라고 말해 주세요.

## 7. 영상 받고 저장하기

1~2분 뒤 Claude가 두 파일을 보내줘요.
- `장르.mp4`: 완성 영상
- `config.json`: 이 영상의 설정 파일 (나중에 다시 만들거나 고칠 때 필요)

⚠️ **Claude 작업 공간은 시간이 지나면 지워져요. 받은 즉시 내려받아서 아래 공유 폴더에 저장해 주세요.**

📁 공유 폴더: *(여기에 공유 폴더 링크 입력)*

```
📁 드럼 패턴 쇼츠
 └─ 📁 002_장르이름
     ├─ 재료.zip
     ├─ 장르_대본.txt
     ├─ 장르.mp4
     └─ config.json
```

## 8. 자주 생기는 문제

| 상황 | 해결 |
|---|---|
| 저장소가 목록에 안 보여요 | 3번 "처음 한 번만" 참고 |
| 대화가 초기화됐어요 / 새 작업에서 이어 하고 싶어요 | 새 작업을 열고 5번 문구 + 재료 zip + 저장해 둔 `config.json`을 같이 첨부하세요 |
| "네트워크가 막혔다"는 메시지가 나와요 | 담당자에게 문의해 주세요 (작업 환경 설정 문제) |
| 디자인(색, 글씨, 배치)을 바꾸고 싶어요 | 직원 작업 범위가 아니에요. 담당자에게 요청해 주세요 |
| 영상 소리가 이상해요 | 원샷 샘플이 맞는지 확인하고, Claude에게 "○○ 소리가 너무 커/작아"라고 말해 주세요 |
